# NLMLab Beta Testing

Thanks for helping test NLMLab.

The useful question is not just whether a screen looks good — it is whether NLMLab stays accurate while you actually play an NLM career.

## Before testing

- Windows PC only for this beta
- Install using the official GitHub release ZIP
- Close NLM before the first installation
- Run the installer and approve the Windows administrator prompt when requested
- Start NLM through Steam and load a career before opening NLMLab

## What to test

### Live squad

- Sync the current squad from NLM
- Confirm the player count, names and positions match NLM
- Confirm injuries, suspensions, at-work players and other unavailability are shown correctly
- Confirm **Available XI** excludes unavailable players
- Confirm **Full-strength XI** includes the normal strongest squad

### Squad analysis

- Change formation
- Check Best XI & Bench
- Check Formation Rater
- Check Formation Depth, including NAT / COVER options
- Check Players to Move On and weekly wages shown
- Check table filters and header sorting

### Player Search

- Search a broad position and compare the candidate count with NLM
- Add age and raw-attribute filters
- Confirm search results narrow correctly
- Load asking wages
- Open player profiles
- Confirm LabLogic changes appropriately by position

### Shortlist / squad impact

- Add several players to My Shortlist
- Confirm `#1`, `XI+`, `DEPTH+` and `SAME` make sense against the current live squad
- Sign or release a player in NLM, sync NLMLab again and confirm the squad comparison updates

### Updating

- Install a newer beta over an older NLMLab version
- Confirm the app still launches and local shortlist/settings remain

## Reporting a bug

Please include:

1. What were you trying to do?
2. What happened?
3. What did you expect?
4. NLMLab version
5. NLM version if known
6. Screenshot(s) where useful

For connection/search problems, say whether NLM itself was open with a career loaded.

## Important beta notes

- NLMLab is read only
- It does not edit NLM saves or submit football actions
- Player Search starts from the candidate pool NLM exposes to the live search context; it is not a dump of every record in the entire game database
- LabLogic is a local position-sensitive comparison tool, not an official NLM ability rating
- Current installers are unsigned, so Windows may display an Unknown Publisher warning
- NLM updates may temporarily change or break the live data interface NLMLab reads
