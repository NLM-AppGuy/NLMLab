NLMLab v4.0.0

Windows release for Non-League Manager.

INSTALL
1. Close NLMLab completely before updating.
2. Extract this ZIP.
3. Run "Install NLMLab v4.0.0.exe".
4. If Windows SmartScreen appears, choose More info -> Run anyway.

NLMLab is read-only: it analyses your live NLM career but does not write changes back to the NLM save.

V4 HIGHLIGHTS
- Live NLM squad sync and raw underlying player attributes
- LabLogic player ratings and squad-impact analysis
- Player Search across contracted players and free agents
- LabLogic, wage, age, distance and raw-attribute recruitment filters
- Automatic asking-wage loading
- True staff attributes, My Staff and Staff Search with role-specific LabLogic
- Availability-aware Best XI with natural, cover and emergency selection logic
- Sortable Squad Overview, Shortlist and Players to Move On tables
- Club-colour identity panel and live NLM club crest
- V4 Squad Overview with Depth Rating, Positional Health, XI-v-cover visual bars, drop-off analysis, Top Priority and Recommended Solutions
