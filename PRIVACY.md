# Privacy

NLMLab is designed as a local-first companion application.

## Live NLM connection

NLMLab connects to the Non League Manager process running on the same Windows PC through a local WebView2 debugging interface.

The beta uses local port **9222** for this connection.

## What NLMLab reads

Depending on the screen/feature, NLMLab can read career information such as:

- current club / season context
- current squad
- player profile information and attributes
- availability / injury / suspension information
- live player-search candidate results
- asking-wage information where NLM exposes it

## What NLMLab stores locally

NLMLab may store local application data such as:

- shortlist entries
- preferences / UI settings
- cached information needed for the current companion workflow

## Accounts and cloud storage

NLMLab does not currently require an NLMLab account.

NLMLab does not currently upload your squad/player database to an NLM App Guy cloud service.

## Read only

NLMLab is designed to read the live career. It does not intentionally edit the NLM save, modify player attributes or finances, submit transfers/contracts, or change scouting knowledge.

## External links

NLMLab / this repository may link to external services such as GitHub, Ko-fi and FFN. Those services have their own privacy policies.

## Beta software

NLMLab is beta software. NLM updates may change the local live-data interface NLMLab relies on.
