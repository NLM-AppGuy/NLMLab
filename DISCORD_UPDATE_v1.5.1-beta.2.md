## 🧪 NLMLab Beta is live

I've ended up merging the two ideas I've been building — **SquadLab + ScoutLab** — into one app.

**NLMLab** connects read-only to your running Non League Manager career and uses the live data from your save, so the biggest pain with SquadLab is gone: **you don't have to keep your squad updated manually anymore.**

### Squad
- Live squad sync from NLM
- Best XI + recommended bench
- Automatically accounts for injuries / suspensions / players unavailable for the next match
- Formation Rater
- New **Formation Depth** screen showing natural + cover options by position
- Players to Move On + weekly wages tied up in those players

### Scout
- Search the player pool NLM exposes to your career
- Filter using the underlying attributes for Pace, Finishing, Passing, Defending, Physicality, Stamina, Aerial, Decisions + Goalkeeping
- **LabLogic** rating out of 100 by position
- Load asking wages
- Shortlist players
- See instantly whether a target is a **#1 / XI+ / DEPTH+ / SAME** compared with your actual current squad

So for example you can now do things like:

**ST · under 25 · Finishing 75+ · Pace 65+**

…and then see how those players actually compare with the strikers already in your squad.

NLMLab is **read only** — it doesn't edit your NLM save or make transfers/changes in the game.

### ⚠️ Beta notes
This beta is **Windows only**. The connection setup is now built into the installer — close NLM, run the installer, approve the Windows prompt if asked, then launch NLM normally. The installer is still unsigned, so Windows may show the usual Unknown Publisher warning.

I've been using it live against my own save, but this is exactly why I'm putting it into beta now — I need it tested across different clubs, levels and careers.
